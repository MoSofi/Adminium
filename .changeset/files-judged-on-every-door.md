A file named in a column that holds files is judged on every way of saving a row: a bulk edit, a save through a table's own rules, a child row and the public API now refuse another record's file, somebody else's upload, a picture not yet cleaned and a file of another kind, as a single save always did. An app update that drops a limit on which rows or which values its role may reach in an add-on's table now counts as giving that role more, and waits for the owner's yes. A link to one screen of an app's own side served by the same server opens it, and one whose address would lead off the server draws no link.
