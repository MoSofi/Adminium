The Files page shows what a file looks like: a picture, a PDF, a video or the start of a text file in its tile and in the drawer, where the browser can show it safely (a text file is shown as its words, never run). In the page editor, a column's settings that need room (a file column's block, the switches for how a value is shown) now take the row's whole width, and a new file column's block starts with its picture shown.
