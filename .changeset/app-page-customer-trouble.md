An app's page says first, at its top, when its customer screens are on and cannot answer: "Customers cannot use this app yet". It names the addresses customers open, and why they see an error (the public API is off, or the app has no public access yet, with where to allow it). Someone who manages API keys can switch the public API on from there; anyone else is told to ask. Before, the only word of it was one line inside the customer row.
