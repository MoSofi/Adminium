Adminium Designer: a Code tab on the build page. It lists the files of the app that can be changed by hand (the screens' source, the dashboard's pages, the design brief, the look and the app's name) and opens them in an editor with line numbers and syntax colours. "Save" keeps every edited file in one version, applies the app, and the Designer is told of the change on its next turn. While the Designer works the files can be read and not changed. A save that does not apply says why and offers to put the files back. The editor is loaded when the tab is first opened.
