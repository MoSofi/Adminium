A secret code in a web address stays out of the request log and the audit log: a mail service's notice address, the link that lets a found person object and be erased, mail and pay links however they are spelled, one-time database hand-offs and prints, and undo codes. Logs written before this release are not rewritten, so if other people can read your logs and you use the "other" mail service without a password, replace its notice address.
