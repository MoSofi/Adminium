The rule editor draws what a step about a person needs: "To" is a pick of the people the rule's record reaches ("The Job's Main contact", or the record itself on a table of people), and says so when nobody is reached; a record input lists only the rows the add-on lets it pick, by the column it names them by; an input's own line shows under it; and a choice whose options each have a line is drawn as cards. In eight languages.
