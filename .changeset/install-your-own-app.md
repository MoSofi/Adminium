Installing an app file someone saved shows a fuller review: where and when it was made, a check against the fingerprint shown when it was saved (a mismatch keeps Install off), Use the existing tables to install onto tables already there with no change to them, a choice for each page whose address is taken, the rules that send data out (they arrive switched off and empty), and the list of things to fill in after installing. That list stays on the app's page, ticked off as each is done, with Upload a newer version in place of Update. A file saved from the database you are installing onto, an older version, or a different app under the same key is refused in a plain sentence. An update that stops part way says where, and Finish the update completes it, even after a reload. The upload no longer asks for a fingerprint up front: paste it on the review instead.
