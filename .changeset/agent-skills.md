Adminium now has agent skills: five skills that teach a coding agent such as Claude Code or Codex to build an app on Adminium from an empty folder, published at github.com/Adminiumjs/skills and installed with `npx skills add Adminiumjs/skills`. They are released with each version, their reference files are produced from this documentation, and a check in CI holds every command, flag, route and import they name to the code.
