The Designer's Code tab can be searched. Ctrl+F (Cmd+F on a Mac) looks for words in the open file: every place is marked, the bar says which one you are on, and Enter goes to the next. The field above the file list looks in every file you can open there, and lists each place by file and line; choosing one opens the file at that line. Both can match case and whole words.
