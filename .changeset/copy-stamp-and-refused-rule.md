A stamp that copies a column of the row (`stamp.set.copy`) is taken for a column of any kind, a number and a date as well as text, and is refused only where it would land in a column of another kind. An install now stops, by name, on a rule it judges wrong for a table it made itself, instead of installing the app without the rule and saying so only in its reply; a rule left out for the operator's sake (they keep their own, the table is shared, an add-on is not there) is still only skipped.
