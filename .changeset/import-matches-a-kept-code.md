An import matches each line on its value as the column keeps it. A customer number kept as a code (`normalize: "code"`) typed `c-1003` in a file now finds the stored `C1003`, in the preview and the run alike, and two spellings of one number in one file are one line made and one line already here. Before, the preview called such a line new and the run then refused it at the column's unique index.
