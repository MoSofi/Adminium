A writer held to their own rows, or their team's, can no longer make a row that is nobody's. A new row of a table that says whose its rows are must name somebody in one of the columns that decide it; left empty, the save is refused (422, the field marked `required`) instead of making a row its own writer could not read back. A role whose reach includes the rows nobody owns still makes one, a column Adminium stamps with the writer needs no name, and a writer nothing limits is not asked. An API key under such a role makes no row there: it can name nobody.
