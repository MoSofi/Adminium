A web address column in a table shows a link only to a web address (`https://`, `http://`), a page of this site, an e-mail address (`mailto:`) or a phone number (`tel:`). A bare address such as `www.example.com` links to it over `https://`. A value such as `javascript:` or `data:` is shown as plain text and never becomes something to click.
