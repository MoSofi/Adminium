The host of this server's public address (`system.publicOrigin`, "Address in email links") can no longer be mapped to an app's staff or customer side either, on the Surfaces screen or on an app's own settings. The entry is refused with the code `public_origin_host` and the same words as for the add-on pages: an app's side there answers the dashboard's pages, and the record links in Adminium's mail, with the app, and a customer side refuses the sign-in and reset pages. Another host is kept as before.
