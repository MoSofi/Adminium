Trial mode and the operator's pieces, tightened. Every refusal an operator's switch causes is now 403 `OFF_BY_OPERATOR` with `details: { question, reason }`: uploads of add-ons and apps, the Designer's uploads and code, **Start with an app**, pay pages, payment webhooks and domains the operator did not list included (a refused domain list also names the `hosts` or `origins`). `/system/info` carries one `offByOperator` object keyed by those questions, `packageUploads`, `designerUploads` and `ownBuilds` among them, in place of `ownCode`. A pay page or payment webhook reached through a percent-encoded address is refused like the plain one. Past a trial's end date no scheduled automation, timed move, report or queued job of the user's runs (exports, the server's own mail and the operator's events do); a record page's consent and payment panels still answer, and drawing a document or settling a project file is refused. Until the operator's page hold has been read at boot every public page counts as hidden, and a failed read is tried again every 30 seconds. The page a hidden door shows uses the shipped words only. `public-content` reads HTML pages first and marks every file and side whose text it cut or left out. Connect Supabase sends the person back to the operator's address they are signed in on. `archive restore --hold` hides the public pages with the operator's hold. `ADMINIUM_OPERATOR_LISTEN` refuses every spelling of "every address". Under `ADMINIUM_NETWORK_POLICY=strict` an add-on's network calls never reach this server or its own network. A project folder never sets `ADMINIUM_TRIAL_MODE`, `ADMINIUM_HOSTED_MODE` or a trial variable, and under either profile a picture service's key is not read from it. On every server, free SQL text that reaches a schema change without being typed in the schema editor (an expression default, a check or a column type carried from the database or a schema import) is refused with 422 when it could end its clause, start a second statement or hide the rest of one, and an expression default now goes in as `DEFAULT (…)`.
