The add-ons that come with Adminium are now 1.0.21: an app's role can be given everything the Customiser's set-up page reads and writes, the set-up adds the starter fonts' files itself, a proof shows a one-colour logo as the laser cuts it, the order-line panel names each part of the design's layout once, and Holiday Calendars' picker starts on the shop's own country. The retired Live Personalizer and Design Studio stay in the set for the shops that have them, and the Add-ons page no longer offers them for a new attach. Staff on an app's own screens can read the server's name and logo, and a table page opens on its own stored sort.
