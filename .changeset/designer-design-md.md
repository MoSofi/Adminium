The Designer takes a Markdown file (`.md`, up to 200 KB) with a message. A `DESIGN.md` that describes a design system (colours, fonts, spacing, corners, do and don't) becomes the design of the app's own screens: the theme is set from it, the brief is written from it, and it stays with the session. Any other document is read as part of what you ask for.
