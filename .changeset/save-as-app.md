Save as app turns what you built on one database into an app file of your own. Start it from Hosted apps or from a connection's card: the quick save takes everything on the database in one press, and More choices lets you pick what goes in, which rows travel as starting or sample rows, and the app's name, key, version and icon. Before anything is written, Check lists what blocks saving (a secret of this server found in the file, named but never shown), what needs a choice, what the new owner fills in after installing, and what is only for your information. People, secrets and history never go in. The download shows the file's fingerprint, and Saved from here keeps every version you saved, with Download again and Save a newer version. `adminium app save` does the same from the command line. Saving needs the right to install apps, and rows, personal values, other people's files and the server's look each need their own right.
