A total that takes the newest row's value (`rollup.latest`) holds the column that keeps the row's key to the type of that key, in the manifest check and on the server, and says so when the child table has no key of one column. The people picker (`GET /people`) searches by name in the query itself and answers the first by name, so an old account is no longer pushed out by newer ones whose address happens to match. A warning that an app's table stops being private is matched by the app's own table, not by a table of the same name in another schema.
