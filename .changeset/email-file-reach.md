An email or campaign now attaches only files its author may read. A file no record holds (a Files library file, or an upload for a form not yet saved) can be attached by the person who uploaded it or by someone who manages files. A file a record holds needs read access to that record's table and row. Before, anyone who could edit emails could attach any library file or any colleague's pending upload.
