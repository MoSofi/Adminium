`ADMINIUM_HOSTED_MODE=on` runs a paid installation on an operator's server, usually a trial after its Upgrade. Its Super Admin is still somebody else on that server, so it keeps every rule of trial mode that guards the operator's machine and network: only the listed database hosts and the one login of `ADMINIUM_SOURCE_URL` on them, `strict`, no SQLite source, files in the data folder only, no add-on or app uploads, a Designer that never writes code the server runs, the project's `.env` not read, its own addresses only, and the operator endpoint and its hide switch. It drops what only limits a free trial: the end date, the banners and the Upgrade button, the size caps and pools of 3, `noindex`, mail only through the operator's relay, and the trial's switches on outgoing calls (webhooks, add-on calls, payments, the Designer's picture search and Figma, telemetry and the update check come back). It needs `ADMINIUM_PUBLIC_ORIGIN` and `ADMINIUM_DATABASE_HOSTS`, and refuses to start while any `ADMINIUM_TRIAL_*` variable is still set, so no old end date or relay carries over. Recreating a trial's container with it on the same meta store, data folder and secret keeps everything stored and takes writes again from the first request, while a hide the operator set on the public pages stays until lifted. A new test boots a trial, the same trial past its end and then the hosted profile on one meta store, on SQLite, PostgreSQL and MySQL.
