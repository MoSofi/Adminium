# @adminium/docs

[docs.adminium.dev](https://docs.adminium.dev) — Astro 5 + Starlight.

Plan: `14-docs-site.md`. Milestone: M10 (M10-T05).

## Commands

```bash
pnpm --filter @adminium/docs dev        # local dev server
pnpm --filter @adminium/docs build      # static site → dist/
pnpm --filter @adminium/docs preview    # serve the built site
pnpm --filter @adminium/docs typecheck  # astro check
```

## The build is the gate

There is no separate test suite; the build enforces the invariants:

- **`starlight-links-validator`** fails the build on any broken internal link.
- **The content-collection schema** (`src/content.config.ts`) requires `title`
  and `description` on every page. A page missing either fails the build.
- **`astro check`** typechecks the config and components.

`pnpm turbo build typecheck lint --filter=@adminium/docs...` is the full gate.

## Layout

```
astro.config.mjs          Starlight config: sidebar, 8 locales, plugins
src/content.config.ts     Frontmatter schema (title + description required)
src/content/docs/         All pages. The sidebar is explicit, not autogenerated.
src/styles/adminium.css   Remaps Starlight's CSS vars onto @adminium/tokens
```

## Conventions

- **`@adminium/tokens` is the only workspace dependency**, enforced by the
  `docs-only-tokens` rule in `.dependency-cruiser.cjs`. The docs site must never
  import product runtime code.
- **No forked token values.** `adminium.css` only ever `var()`s into tokens; it
  never restates a hex.
- **No CDN.** Fonts are bundled via `@adminium/tokens/fonts.css`. The built site
  makes zero external asset requests.
- **The sidebar is explicit** so ordering is deliberate and stable across
  versions (14-docs-site.md §9 — a future `/v1/` prefix must not reshuffle nav).

## i18n

All 8 locales are declared from day one (`root`/en, de, fr, cs, da, zh-CN,
zh-TW, ar-RTL) so the language switcher and URL structure never change when
translations land. Only `root` carries content at v1; Starlight falls back to
English for the rest, so no locale produces a broken page.

Locale keys map 1:1 onto `@adminium/i18n`'s `LOCALES` registry. Content breadth
for the other locales is M14.

## Style guide

Task-first titles (`Connect a PostgreSQL database`, not `PostgreSQL`). The
frontmatter `title` is the page's only H1; body headings start at `##`. Shortest
command that works first, with its expected output.

**Document what shipped.** Read the source before documenting a flag. If a
feature has not shipped, the page says so rather than describing it — see
`reference/manifest.md` for the pattern.
